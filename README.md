# Radiofrequency & Antenna Systems Analysis (Python)

This repository contains a series of technical simulations and calculations developed in **Python** using **Jupyter Notebooks**. The project focuses on the mathematical modeling of electromagnetic phenomena and antenna performance.

## Technical Highlights
- **Mathematical Modeling:** Implementation of complex number calculations and phasors for radiation fundamentals.
- **Antenna Simulation:** Analysis of radiation patterns for wire, aperture, and array antennas.
- **Propagation Models:** Development of scripts to simulate wave propagation in different environments.

## Tools & Libraries
- **Python 3**
- **Jupyter Notebook:** For interactive documentation and data visualization.
- **Scientific Computing:** Use of numerical libraries to solve electromagnetic equations.

## Academic Context
These notebooks were created as part of my **Telecommunication Engineering** degree at the **University of Valladolid**. They demonstrate the application of software development to solve advanced physics and engineering problems.
